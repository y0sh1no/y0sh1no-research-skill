# 文献地图与方向探索

先读取[运行环境](references/library/packaging/runtime/portable.md)。以用户的兴趣、应用目标和资源为起点，帮助其理解领域并比较研究方向；已有资料足够时直接分析。

## 工作方法

1. 把宽泛主题拆成研究对象、任务设定、评价目标和约束，找同名不同义及跨领域术语。用户已给出具体问题时围绕它组织，不要求重新选题。
2. 用综述/经典工作建立坐标，再覆盖主要方法家族和近期变化。按[检索与综合](references/library/shared/literature.md)查找实际来源，记录本次范围、检索日期和已读深度。
3. 按问题设定、假设、机制、数据和计算条件比较代表工作。说明方法家族之间的继承、替代、互补与适用边界，避免只按年份排列摘要。
4. 对看似开放的问题，检查它是未解决、条件发生变化、缺少解释，还是仅在当前检索中未出现。将作者写的 limitations 与已有证据支持的问题分别呈现。
5. 结合可获得数据、复现条件、研究价值和用户资源比较方向。给出支持与约束，方向取舍由用户决定。

## 交付

按请求提供领域地图、代表文献、重要分歧、方向比较和阅读路径。用表格比较方向时，列研究问题、现有最好解释/方法、剩余缺口、可行入口和证据来源。阅读顺序服务于理解：先掌握问题与强代表工作，再深入最相关分支。

若覆盖不完整，指出具体未查分支。用户要求快速入门时交付可用地图，不为了数量持续搜集。每条重要判断遵循[证据与主张](references/library/shared/evidence.md)。

## 可选协作

不同术语、任务设定或方法家族可以分支检索；整合时统一比较字段、去重并检查遗漏。任务需要独立方向建议时，各分析者先从共同资源约束出发，再比较建议及其证据。按[协作方法](references/library/shared/collaboration.md)选择实际执行方式。
