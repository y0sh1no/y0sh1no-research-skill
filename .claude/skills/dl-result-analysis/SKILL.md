# 结果分析与解释

先读取[运行环境](references/library/packaging/runtime/portable.md)。围绕用户当前比较或解释问题读取实际结果、配置和指标定义。

## 分析方法

1. 建立结果到运行的对应：方法、数据版本/划分、预算、seed、checkpoint、指标、失败或缺失。区分论文值、本地运行值和示例值。
2. 明确实验单位及依赖结构，按[统计参考](references/library/shared/statistics.md)处理受试者/任务/运行/折/seed。先检查可比性、指标方向和聚合，再计算效应与不确定性。
3. 回到原始结果复算关键数值，区分百分点、相对变化和误差降低。检查缺失、异常和失败运行，说明纳入规则。
4. 从总体比较深入与问题有关的子群、曲线、样本和配置差异。事后分析标为探索性；避免只展示支持偏好解释的部分。
5. 按“观察 → 解释假说 → 可支持结论”组织。对机制保留竞争解释，分别判断结果、数值及实验条件，使用[证据参考](references/library/shared/evidence.md)。

## 输出选择

用户要结论时先给判断与关键数值；要报告/绘图时提供实际分析、表格和图形，采用[图表参考](references/library/shared/figures.md)。无需每次强制输出固定数量图或文件。

数据缺少重复时可以报告已观察差异，不能补造方差/区间；相关重复不能伪装独立大样本。无显著差异不证明等效。失败或负结果可能帮助缩小机制边界，保留条件。

记录进入结论的原始字段、聚合与配置，便于论文和后续复算。建议实验针对具体未解决项，不自动执行。

## 可选协作

可独立复算关键结果，分开核查统计、协议、失败样本与解释。整合依靠计算和原始材料，按[协作方法](references/library/shared/collaboration.md)保留重要分歧。
