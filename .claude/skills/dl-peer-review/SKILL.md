# 论文与研究评阅

先读取[运行环境](references/library/packaging/runtime/portable.md)，再按任务读取[评阅与评分](references/library/shared/review.md)。可进行整体审阅或用户指定的理论、实验、实现、引用、叙事等专项检查。

## 评阅方法

1. 确认稿件版本、阅读范围和目标量表。用户指定会议/年份时查实际评分定义；未指定而要求打分时明确采用自定义量表。
2. 准确复述贡献和方法，定位作者核心主张。分别检查正确性、新颖性、意义、证据和表达，不预设结论。
3. 回查支撑重要意见的页/节/公式/图表/代码/结果。识别已经确认的错误、影响主张的疑虑、缺少解释和可选扩展。
4. 对每项重要问题说明位置、依据、严重性、对结论的影响，以及什么证据/修改能改变评价。材料缺失只限定对应判断。
5. 按实际意义和修复成本给优先级。认可已经成立的贡献和正确部分，不为了角色显得苛刻而制造问题。

## 评分

用户要求整体评分时，给量表、评分理由和信心；专项检查只给局部判断。分数不能转换成录用概率。已有历史录用结果也不能决定当前稿件科学正确性。

多个整体 reviewer 使用共同稿件和量表，首轮可以各自评分；保留评分范围、理由和重要分歧。汇总优先看原始证据，不要求单一跨家族模型最终裁决，也不为获得正面分数持续重审。

## 协作与交付

按用户请求和任务需要，选择独立整体评阅、互补专项检查或数值/引文复核。提供共同原始材料，第一轮暂不传作者偏好或他人分数。见[协作方法](references/library/shared/collaboration.md)。Work 使用单 agent 维度评价。

交付贡献理解、优点、具体问题、重要提问、评分（若要求）和修改优先级。复审只核查本次改动及其影响，不默认重跑所有意见。
