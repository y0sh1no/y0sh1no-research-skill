# 论文评阅与评分

## 量表和阅读范围

用户指定会议、年份或赛道时，查实际 reviewer guide 和评分定义。若无法获取，说明采用自定义量表。综合 reviewer 阅读相同版本的全文与约定材料；只看摘要或实验表的核查者给局部意见。

审阅先准确复述贡献，再用证据判断。不要预设论文必然有致命问题，也不要为了友善压低真实缺陷的严重性。

## 重要判断

| 维度 | 可定位的问题 |
|---|---|
| 正确性 | 推导条件、实现与方法一致性、协议/指标、证据是否支持主张 |
| 新颖性 | 最接近工作及明确差异，已知模块组合产生了什么新知识 |
| 意义 | 谁受益、收益量级/成本、适用范围，是否回答有价值的问题 |
| 实验证据 | 基线强度、公平条件、诊断、重复性、失败/负结果 |
| 表达与可复现性 | 定义、关键细节、图表信息、引用语义、可复现入口 |

每条重要意见带位置、理由、严重性和对结论的影响。区分已经证明的错误、合理疑虑、缺少解释和可选扩展。改进建议对应问题；不把增加任意数据集或最新组件当成普遍录用条件。

## 未指定量表时

用户要求评分但未给量表，可采用明确标为**自定义**的 1–5 整体评价：1 有核心正确性问题；2 关键证据/贡献缺口；3 有价值但核心判断尚待补强；4 主要主张得到较好支持；5 证据与贡献突出且重要问题已处理。按实际材料说明理由与信心；没有材料就不补造分数。

整体评分和分维度评价可以同时给，但不把维度分数机械平均为正式会议分数。修改优先级由影响、可修复性和成本判断。分数变化应能追溯到具体新证据或改动。

## 多 reviewer

读共同稿件、用共同量表，首轮独立给整体判断与分数，之后对重要分歧做证据核验。中位数/范围只描述这些模型输出，不能当成录用概率、统计置信区间或真人审稿分布。方向相同的相关错误仍可能发生。

用户要求从多个专业视角检查时，按任务决定采用多个整体 reviewer 或局部专家。Work 给单 agent 维度评价；可提出更换视角后的问题，但不能声称已有独立审稿团。
